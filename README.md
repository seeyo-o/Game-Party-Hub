# 🎮 Discord Party Game Hub

Web aplikasi multiplayer party game untuk teman-teman nongkrong di Voice Chat Discord! Dibangun menggunakan HTML5, Tailwind CSS, CSS Variables, Modular Vanilla JavaScript, dan Firebase Realtime Database.

## 🕹️ Game yang Tersedia:
1. **Tentang Kita** (48 Kartu Deep Talk, Persepsi & Tantangan Spontan Voice Chat, Roulette Penjawab, 3D Flip Card)
2. **Siapa di Antara Kita** (The Voting Game dengan 3 suara setara, progress bar, dan Sidang Interogasi Host)
3. **Guess Who? Battle Royale** (Papan Wajah Anime via Jikan API & Tokoh Dunia via Wikipedia, Sistem Gugur Permanen, Skor +10/-5, Catatan Target per Lawan)

## 🚀 Cara Menjalankan Lokal:
Buka `index.html` menggunakan Live Server atau HTTP server lokal:
```bash
# Python
python -m http.server 3000

# Atau gunakan VS Code Live Server Extension
```

## 🌐 Deployment ke Vercel:
1. Inisialisasi Git di folder ini:
   ```bash
   git init
   git add .
   git commit -m "feat: initial discord party game hub"
   ```
2. Hubungkan ke GitHub repo dan push.
3. Import repo di dashboard Vercel ([vercel.com](https://vercel.com)) dan klik **Deploy**.
